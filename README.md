# ФОРМА — концепт магазина кроссовок

Дизайн-концепт русскоязычного интернет-магазина кроссовок. Статический сайт:
HTML, CSS и один файл JavaScript, без сборки и без зависимостей.

**Демо:** https://pizko.github.io/shos/

> Модели, цены и характеристики — демонстрационные. Заказ не оформляется,
> оплата не проводится, данные форм никуда не передаются.

## Дизайн-направление: «Асфальт и натрий»

Палитра города ночью под натриевым фонарём — тёплый янтарь на холодном мокром
асфальте. Один акцентный цвет, никаких градиентов.

| Токен | Значение | Роль |
|---|---|---|
| `--asphalt` | `#14161A` | фон |
| `--slab` | `#1C1F25` | карточки и панели |
| `--sodium` | `#FF8A2B` | единственный акцент |
| `--chalk` | `#EDEAE4` | основной текст |
| `--fog` | `#8A8F98` | вторичный текст |
| `--line` | `#2C3038` | границы |

**Шрифты** — три роли: `Unbounded` (заголовки), `IBM Plex Sans` (текст),
`IBM Plex Mono` (цены, размеры, характеристики). Все с кириллицей.

**Радиусы** — ровно два: `2px` для элементов управления, `14px` для карточек.

**Подпись проекта** — протектор. Один SVG-символ работает в трёх местах:
след, уходящий вглубь первого экрана (отпечатывается по шагу при загрузке),
оттиск на фото товара при наведении и разделитель секций.

## Что изменено по сравнению с исходным шаблоном

| Было | Стало |
|---|---|
| Кружки-«светофор» от macOS на карточке кроссовок | убраны — к обуви отношения не имели |
| Градиент `#06B6D4 → #EC4899` на кнопках | один натриевый акцент без градиента |
| «Три ритма» — вёрстка тарифной таблицы SaaS (средняя карточка `scale(1.05)`) | три равные карточки маршрутов с реальными данными: покрытие, дистанция, темп |
| Системный `<select>` для размера | сетка фишек с состоянием «нет в наличии» |
| Системный `<input type=range>` | оформленный ползунок с моноширинным отсчётом |
| Один шрифт Manrope на все роли (`Aspekta` из брифа не подключался) | три гарнитуры под три роли |
| Шесть разных радиусов | два |
| Фиолетовое свечение `#7C3AED` | свет уличного фонаря |
| Товары продублированы в HTML трёх страниц и в `products.json` | один источник — `assets/products.js` |

Исправленные ошибки:

- `<iconify-icon>` использовался на всех страницах, но загрузчик библиотеки не
  подключался — иконки поиска, закрытия и корзины не отображались вообще.
  Заменены на встроенный SVG-спрайт.
- Фильтры «Все / Город / Бег» не фильтровали, а категория «Каждый день»
  отсутствовала в списке. Теперь фильтруют, все четыре категории на месте.
- `<section id="budget">` и `<input id="budget">` имели одинаковый `id`, из-за
  чего ползунок подбора не подключался.
- Сетки не могли сжиматься уже своего содержимого (`min-width:auto`) — текст
  выходил за поля на телефоне.
- Фокус не переходил в открытую панель корзины; добавлены перевод фокуса,
  ловушка `Tab` и возврат фокуса при закрытии.

## Анимация

Оркестрованная последовательность при загрузке первого экрана: строки заголовка
поднимаются из-под маски, следом отпечатывается след протектора — издалека к
зрителю. Дальше по странице — появление секций при прокрутке со сдвигом по
соседям, оттиск протектора на фото при наведении, бегущая строка (замирает при
наведении), выдвижная корзина и отклик счётчика при добавлении пары.

`prefers-reduced-motion: reduce` отключает всё это целиком — и в CSS, и в JS.

## Структура

```
index.html      главная
catalog.html    каталог с фильтрами (?cat=city|run|every)
product.html    карточка товара (?id=…)
cart.html       корзина
checkout.html   оформление (демонстрационная форма)
assets/
  site.css      дизайн-система и вёрстка
  app.js        корзина, фильтры, подбор, анимация
  products.js   данные о товарах — единственный источник
  favicon.svg
```

Корзина хранится в `localStorage` браузера и живёт между страницами.

## Локальный запуск

```bash
python3 -m http.server 8000
```

Затем откройте http://localhost:8000/

## Замечание об изображениях

Фотографии подгружаются с Unsplash по прямым ссылкам. Это стоковые снимки
обуви существующих марок — они стоят как заглушки на месте будущей предметной
съёмки. Логотипы приглушены обесцвечиванием карточек; на первом экране
фотографии нет намеренно. Перед коммерческим запуском их нужно заменить
собственными снимками.
