# ФОРМА — комплект для подключения к CMS

Это статический демонстрационный комплект интернет-магазина кроссовок. Он подготовлен без привязки к конкретной CMS: шаблоны, данные, стили, клиентская логика и JSON-LD разнесены по отдельным файлам.

## Что входит

- `index.html` — главная страница;
- `catalog.html` — каталог с фильтрацией, поиском, сортировкой и быстрым просмотром;
- `product.html` — карточка товара с выбором размера;
- `cart.html` — корзина с изменением количества;
- `checkout.html` — демонстрационное оформление заказа;
- `assets/styles.css` — единый файл всех стилей;
- `assets/favicon.svg` — локальная иконка сайта;
- `assets/app.js` — общая клиентская логика;
- `assets/refine.css`, `assets/refine.js` — точечные доработки поверх исходного оформления (см. ниже);
- `data/products.json` — демонстрационные товары;
- `data/site.json` — название, базовый URL и режим демонстрации;
- `templates/*.html` — CMS-независимые шаблоны с переменными `{{...}}`;
- `schema/*.jsonld` — отдельные копии разметки Schema.org, встроенной в страницы;
- `tools/render.py` — сборка страниц и JSON-LD из файлов `data/*.json`;
- `tools/verify.py` — локальная структурная проверка.

## Обновление демонстрационных данных

1. Измените `data/products.json` и `data/site.json`.
2. В каталоге `cms-ready` выполните:

   ```bash
   python3 tools/render.py
   python3 tools/verify.py
   node --check assets/app.js
   ```

HTML, `assets/products.js` и JSON-LD будут заново созданы из одного источника данных. Это снижает риск расхождения видимой цены и цены в структурированной разметке.

## Разметка Schema.org

| Страница | Типы в JSON-LD |
| --- | --- |
| Главная | `WebSite`, `WebPage` |
| Каталог | `WebSite`, `CollectionPage`, `BreadcrumbList`, `ItemList` |
| Товар | `WebSite`, `WebPage`, `BreadcrumbList`, `Product`, `Offer` |
| Корзина | `WebSite`, `WebPage`, `BreadcrumbList` |
| Оформление | `WebSite`, `CheckoutPage`, `BreadcrumbList` |

Разметка товара сейчас содержит только доступные демонстрационные данные: название, изображение, категорию, описание, цену и валюту. Бренд, артикул, GTIN/MPN, наличие, отзывы, доставка и возврат не выдумываются. Генератор добавляет часть этих полей только при наличии значений в данных CMS.

## Перед публикацией

1. Укажите реальный домен в `data/site.json` и только после этого выключите `demo`.
2. Замените демонстрационные товары, цены и изображения реальными данными.
3. Подключите реальные URL CMS и канонические адреса страниц.
4. Передавайте в JSON-LD ту же цену, валюту, наличие и описание, которые посетитель видит на странице.
5. Добавляйте организацию, бренд, SKU, GTIN/MPN, наличие, отзывы, доставку и правила возврата только из подтвержденных данных магазина.
6. Оставьте корзину и оформление закрытыми от индексации.
7. Подключите серверную обработку заказа, согласие с политикой обработки данных и платежного провайдера. Текущая форма ничего не отправляет, не сохраняет и не проводит оплату.
8. Проверьте публичные страницы после интеграции в Rich Results Test и валидаторе Schema.org. Локальная проверка подтверждает структуру файлов и JSON, но не гарантирует расширенный результат в поиске.

Соответствие полей шаблона полям CMS описано в `CMS_FIELDS.md`.

## Доработки поверх исходного комплекта

Всё оформление, шрифты и структура — исходные. Поверх подключены два файла,
которые меняют ровно две вещи и легко снимаются: достаточно убрать `refine.css`
и `refine.js` из `<head>` и конца `index.html`.

**Витрина на первом экране.** Вместо равномерного вращения куб теперь
поворачивается по шагам: грань подаётся ровно, держится около трёх секунд,
затем чётко переворачивается на следующую. Добавлены скруглённые края граней,
световая кромка и свет сверху, а точка схода перспективы мягко следует за
курсором. Вылет граней исправлен с `30vh` на `25vh` — при ребре `50vh` коробка
иначе не сходится и края торчат наружу.

**Подбор по бюджету.** Кнопка «Показать варианты» больше не градиентная:
сплошная белая с чёрным текстом — тот же приём, что у активного фильтра
каталога и центральной карточки «Трёх ритмов». Градиент `#06B6D4 → #EC4899`
остальных кнопок сайта не тронут.

`prefers-reduced-motion` отключает и вращение, и параллакс.
