# Карта полей для CMS

Платформа CMS пока не выбрана, поэтому названия ниже логические. При интеграции разработчик сопоставляет их с полями WordPress/WooCommerce, 1С-Битрикс, OpenCart или другой системы.

## Настройки сайта

| Логическое поле | Сейчас | Назначение |
| --- | --- | --- |
| `siteName` | `ФОРМА` | Название сайта и сущности `WebSite` |
| `baseUrl` | `https://example.com` | Основа абсолютных URL в JSON-LD |
| `demo` | `true` | Включает `noindex, nofollow` на всех страницах |
| `organization` | `null` | Подтвержденные данные юридического лица или бренда |

## Товар

| Поле | Обязательность для этого шаблона | Использование |
| --- | --- | --- |
| `id` | обязательно | Идентификатор корзины и ключ шаблона |
| `name` | обязательно | Карточка, корзина, `Product.name` |
| `price` | обязательно | Видимая цена и `Offer.price` |
| `category` | обязательно | Фильтры и `Product.category` |
| `sizes` | обязательно | Выбор варианта товара |
| `image` | обязательно | Карточка и `Product.image` |
| `description` | для рабочего магазина | Описание товара и `Product.description` |
| `sku` | при наличии | `Product.sku` |
| `brand` | при наличии | `Product.brand` |
| `gtin13` или `mpn` | при наличии | Идентификатор товара |
| `availability` | при наличии | `Offer.availability`, URL из словаря Schema.org |
| `color` | при наличии | `Product.color` |

## Правила интеграции

- Видимые сведения о товаре и JSON-LD должны формироваться из одной записи CMS.
- Для каждого товара нужен собственный постоянный URL; демонстрационная сборка показывает первый товар на `product.html`.
- Корзина в прототипе хранится в `localStorage`. Рабочий магазин должен использовать корзину и сессию выбранной CMS.
- Оформление заказа в прототипе выполняет только проверку полей. Передача заказа, расчет доставки, платежи и согласия подключаются на серверной стороне CMS.
- Нельзя автоматически подставлять наличие, рейтинг, отзывы, бренд, идентификаторы, доставку или возврат при отсутствии подтвержденных значений.
- После интеграции нужно проверить HTML страницы товара, ответ сервера, канонический URL и встроенный JSON-LD на публичном адресе.
